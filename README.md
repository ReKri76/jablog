# Jablog

> **Тестовый демонстрационный стенд:** [https://77.110.115.36.nip.io/](https://77.110.115.36.nip.io/) UPD: я там удалил все картинки случайно, позже исправлю

Нечто среднее между Reddit и обычной имиджбордой.

В отличие от традиционной имиджборды, здесь есть возможность создавать доски и настраивать для них права доступа. В отличие от Reddit, писать может кто угодно (если не задано иного в правах доступа).

## Терминология

* **Доска (сабреддит)** — основная единица. Содержит учетные записи и треды.
* **Учетная запись** — к каждой доске обязательно прикреплена как минимум одна учетная запись (учетная запись владельца, которая создается при создании доски и является ее синонимом). Все остальные делятся на два вида:
    * **Юзеры** — создаются владельцем, права для них определяются на этапе создания доски.
    * **Анонимы** — все остальные посетители доски, имеющие дефолтные права.
* **Тред (тема)** — старт обсуждения. Обязан содержать картинку, может содержать текст, к нему привязаны посты.
* **Пост (ответ)** — сущность, прикрепленная к треду-родителю. Содержит текст и может содержать картинку.

## Права доступа

Права доступа к доске определяются при создании по UNIX-подобной системе и состоят из 12 модификаторов для трех групп: **(owner)**, **(group)**, **(other)**. Каждая группа содержит 4 модификатора.

### Модификаторы
* `r` — чтение доски (read board)
* `w` — создание постов (write posts)
* `d` — право на удаление (can delete)
* `x` — доступ к тредам (have access to threads)

### Допустимые комбинации
* `rwdx` — полный доступ (full access)
* `rwd-` — чтение тредов и постов, создание и удаление постов
* `rw-x` — чтение тредов и постов, создание постов и тредов
* `rw--` — чтение тредов и постов, создание постов
* `r-dx` — чтение тредов и постов, удаление постов и тредов
* `r-d-` — чтение тредов и постов, удаление постов
* `r--x` — чтение тредов и досок
* `r---` — чтение тредов
* `----` — нет доступа (have no access)

*Некорректные комбинации (без прав на чтение):* `-wdx`, `-wd-`, `-w-x`, `-w--`, `--dx`, `--d-`, `---x`.

### Пример: `rwdxrw-xr--x`
* **Владелец (`rwdx`)**: имеет право удалять что угодно на этой доске.
* **Залогиненные юзеры (`rw-x`)**: могут создавать треды и посты.
* **Анонимы (`r--x`)**: могут только читать.

## Сборка и запуск

**Требования:** наличие `docker` и `docker-compose`.

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/ReKri76/jablog.git
   ```
2. Перейдите в папку проекта и создайте конфигурационный файл:
   ```bash
   cd jablog
   touch .env
   cat .env_example > .env
   ```
3. Отредактируйте файл `.env`, заменив все переменные на актуальные:
   ```bash
   vim .env
   ```
4. Запустите контейнеры в фоновом режиме:
   ```bash
   docker compose up -d
   ```
