# Jablog

> **Тестовый демонстрационный стенд:** [https://77.110.115.36.nip.io/](https://77.110.115.36.nip.io/)

Нечто среднее между Reddit и обычной имиджбордой.

В отличие от традиционной имиджборды, здесь есть возможность создавать доски и настраивать для них права доступа. В отличие от Reddit, писать может кто угодно, если иное не задано правами доступа.

## Терминология

* **Доска (сабреддит)** — основная единица. Содержит учётные записи и треды.
* **Учётная запись** — к каждой доске обязательно привязана как минимум одна учётная запись владельца, которая создаётся при создании доски и является её синонимом. Все остальные учётные записи делятся на два вида:
    * **Юзеры** — создаются владельцем; права для них определяются при создании доски.
    * **Анонимы** — все остальные посетители доски, имеющие права доступа по умолчанию.
* **Аккаунт** — сущность, объединяющая учётные записи пользователя на разных досках. Один аккаунт может иметь несколько учётных записей, при этом одна учётная запись может быть связана с несколькими аккаунтами.
* **Тред (тема)** — начало обсуждения. Обязательно содержит картинку, может содержать текст; к нему привязаны посты.
* **Пост (ответ)** — сущность, прикреплённая к родительскому треду. Содержит текст и может содержать картинку.

## Права доступа

Права доступа к доске определяются при её создании по UNIX-подобной системе и состоят из 12 модификаторов для трёх групп: **owner**, **group** и **other**. Каждая группа содержит 4 модификатора.

### Модификаторы

* `r` — чтение доски (read board)
* `w` — создание постов (write posts)
* `d` — право на удаление (can delete)
* `x` — доступ к тредам (have access to threads)

### Допустимые комбинации

* `rwdx` — полный доступ (full access)
* `rwd-` — чтение тредов и постов, создание и удаление постов
* `rw-x` — чтение тредов и постов, создание постов и тредов
* `rw--` — чтение тредов и постов, создание постов
* `r-dx` — чтение тредов и постов, удаление постов и тредов
* `r-d-` — чтение тредов и постов, удаление постов
* `r--x` — чтение тредов и досок
* `r---` — чтение тредов
* `----` — нет доступа (have no access)

*Некорректные комбинации (без прав на чтение):* `-wdx`, `-wd-`, `-w-x`, `-w--`, `--dx`, `--d-`, `---x`.

### Пример: `rwdxrw-xr--x`

* **Владелец (`rwdx`)** — имеет право удалять что угодно на этой доске.
* **Залогиненные юзеры (`rw-x`)** — могут создавать треды и посты.
* **Анонимы (`r--x`)** — могут только читать.
